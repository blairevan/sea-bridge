## 1. 核心升级内容

支持在 Sea-Bridge Web 控制台新建会话弹窗中选择模型的推理强度（Reasoning Effort）：
1. **协议与元数据扩展**: Codex App Server 客户端与只读服务扩展 `model/list` 解析，提取 `defaultReasoningEffort` 与 `supportedReasoningEfforts`，并在 `turn/start` 中按模型支持精准传递 `effort` 参数；
2. **Web API 与参数校验**: `POST /api/sessions` 增加对 `reasoningEffort` 的安全字符集与长度限制校验；
3. **前端动态联动**: 新建会话表单新增推理强度下拉框（`#create-reasoning-effort`），提供“使用模型默认设置”以及对齐桌面端默认视野的“低（轻度）”、“中”、“高”三档；模型不支持推理时自适应禁用。
