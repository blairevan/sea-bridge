# 页面内容保留审查 v0.3.3

## 统一规则

普通网络失败、SSE 失败、超时、手动重连、进入后台：保留当前页面全部已加载内容、草稿、筛选、选项、分页和阅读位置。只暂停服务端操作，显示上次数据提示。不写入浏览器持久化缓存，不自动重发写请求。

认证 401、设备撤销、主动退出登录和全局脱敏版本变化：清理服务器来源内容，重新核验后才能恢复。

## 清理路径逐项核查

| 内容或路径 | 处理 |
| --- | --- |
| 概览统计、来源卡片、最近会话 | 普通断线保留；成功获取概览后更新 |
| 会话列表、消息、历史分页、阅读位置 | 普通断线保留；最新轮询不重置旧历史分页 |
| 操作记录、日志 | 普通断线保留；操作轮询合并新记录，保留已加载旧页和分页边界 |
| 设置和设备列表 | 普通断线保留；保存和撤销按钮禁用 |
| 新建弹窗、项目和模型选择 | 普通断线不关闭、不清空；弹窗显示连接状态和重试入口；目录全部请求确认后才替换 |
| 发送与新建草稿 | 普通断线不清空；已接受回执只清除本次原草稿，保留等待期间新输入内容 |
| 图片与已展开内容 | 无变化轮询不重建消息；有新消息时复用未改变的旧消息节点 |
| 断线后返回旧 GET 响应 | requestApi 的 paused/settings 校验继续阻止未核验响应覆盖页面 |
| 用户主动切换会话 | 重置会话级历史状态并读取目标会话；此明确用户操作与断线清理区分 |
| 成功提交/用户主动关闭弹窗 | 保留原有明确用户操作结果；普通断线不会模拟关闭 |
| 成功响应为空列表 | 按实际来源更新为空状态；请求失败不当作空列表 |
| 登录失效/撤销/退出 | 完整清除服务器来源内容 |
| 脱敏版本变化 | 完整清除旧策略内容，重新核验策略后读取 |
| 图片请求失败 | 仅替换对应图片占位，保留其他消息 |

## 验证

回归覆盖所有保留容器、统计、消息、草稿、阅读位置、项目选择、新建弹窗和禁用写操作；同时验证完整失效分支依然清理容器。补充目录失败、无变化及新回复 DOM 复用、发送期间新草稿、操作记录分页的回归。

执行命令：bun run typecheck、bun test、bun run build、git diff --check。设备上的实际断网、后台往返和图片体验仍待手机验收。

### v0.5.0 标题选择与提示

普通断线保留已选标题、原 ID、操作列表和已知记录标题；离线建议仅从已加载会话生成，不额外发请求。登录失效、撤销、脱敏版本变化时清理提示列表、查询计时器、选择和标题输入；序号阻止此前请求回填旧策略下的标题。
