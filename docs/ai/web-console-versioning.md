# Sea-Bridge 版本规则

应用版本以 package.json 的 version 为唯一来源，使用主版本.次版本.补丁版本。

- 不兼容变更递增主版本；新功能递增次版本；问题修复递增补丁版本。
- 每次发布包含代码变化时递增版本，避免同一版本代表不同发布内容。
- 页面登录栏、配对页和静态资源 URL 自动读取该值。源码 HTML 使用占位符，由开发服务器或构建脚本注入。
- 部署快照命名为 sea-bridge-v版本号-时间戳，时间戳用于区分部署批次。
- 全局脱敏设置的 settings version 是同步序号，与应用发布版本独立。
- 历史验收记录保留原编号用于追溯；后续发布使用应用版本号。

## v0.2.0

- 引入统一应用版本与页面显示。
- 进入会话默认定位最新消息；增加最新消息、最早已加载快捷定位。
- 包含此前已验收的断线重连、顶部提示及只读会话保留行为。

## v0.3.0

- 运行概览升级为摘要统计、来源独立能力、Telegram 接收证据和最近会话四部分。
- 最近一页统计显式标注范围与部分来源失败，概览独立于会话页搜索筛选。
- 手机单列能力卡、桌面双列；保留断线只读会话与写操作保护。

## v0.3.1

- Codex 投递后的状态增加 rollout 生命周期证据兜底，不再仅依赖 Hook。
- 区分会话正在执行、会话投递后结束和精确 turn 证据；拒绝早于投递时间的 rollout 证据。

## v0.3.2

- 服务不可达或后台暂停时保留概览统计、来源卡片、最近会话，标记为上次数据。
- 登录失效、设备撤销、脱敏版本变化继续完整清空；恢复成功刷新概览后移除旧数据提示。

## v0.3.3

- 统一断线只读保留全部已加载页面、草稿、弹窗、目录选择和分页。
- 目录请求成功后才替换；操作轮询保留旧页；消息 DOM 复用保留图片；发送回执不擦掉新草稿。
- 新建弹窗提供连接重试；暂停时禁用撤销设备等全部服务端写操作。

## v0.4.0

- 概览统计成为全部、运行中、等待审批会话的快捷入口；执行状态在服务端筛选后分页。
- 来源能力直接进入来源会话、新建表单或项目/模型只读目录；Telegram 进入操作与日志，脱敏状态进入设置。
- 最近会话打开对应对话并重置不相关筛选；概览新建入口不自动派发。
- 手机触控区域至少 44px，统计、能力、来源入口提供方向提示及按下反馈。
- 断线保留概览与目录；支持浏览缓存列表和已加载当前对话，不自动获取未加载内容或执行写入。

## v0.5.0

- 操作记录筛选区使用明确网格：桌面三列、手机两列、320px 窄屏单列；统一 44px 控件高度并约束日期输入宽度。
- 会话 ID 输入改为会话标题 combobox，500ms 防抖查找，支持来源/更新时间提示、键盘选择、过期查询结果丢弃。
- 选中会话立即按来源与原 ID 筛选，标题不作为 ID 传递；来源变化清理不匹配的选择。
- 记录列表优先展示来源提供的标题；目录读取失败仍保留操作记录及此前有效标题。断线保留已加载内容，认证/脱敏策略边界清理标题提示与选择。

## v0.5.1

- 提交前审查修复操作记录状态筛选的陈旧行：成功刷新当前查询窗口时替换已覆盖记录，保留更早分页；完整空结果清除当前记录与分页。网络失败仍保留已加载内容。
- 刷新窗口增减记录时同步调整数字分页 offset，避免状态变化后下一页跳过一条记录。
