# 手机会话阅读空间优化

用户已确认此前提出的五项方案。使用现有 feature/web-console，无新依赖。

- 手机品牌栏 44px、导航约 40px；会话返回、单行标题、状态合成一行。
- 输入框一行起步，自增高最多三行；发送按钮并排，状态/核查保留在下方。
- 完整历史说明改为可展开提示，与加载较早按钮置于消息滚动区域顶部。
- VisualViewport 高度及 offsetTop 约束已登录界面，键盘聚焦时隐藏品牌栏/主导航，保留会话返回及输入框；无 API 时使用 CSS dvh。
- 卡片减小间距/内边距，不缩小正文阅读字号。
- 最新消息跟随逻辑保留；旧页前插按 scrollHeight 增量保持原阅读锚点。
- 验证输入增高/viewport/分页回归与移动浏览器真实布局，真实 iPhone 键盘仍需设备验收。
