# Telegram 终态纠正通知设计

用户已确认：同一轮已发送的“已中断”被官方历史修正为完成时，更新原 Telegram 消息，不新增通知。

- 仅作用于 interrupted → completed 的纠正指纹；普通通知仍发送新消息。
- 按 chat/thread/turn 精确查找原中断消息，复用消息 ID、更新正文并保留回复按钮。
- 原通知尚未发送时，继续现有 pending 替换机制，最终只发送完成通知。
- 编辑成功后原子更新回复映射与纠正 outbox 状态。编辑失败沿用退避重试，不回退到发送新消息。
- Telegram 返回 message is not modified 时视为成功，允许编辑成功但本地未落库后的恢复。
- 若纠正在旧通知发送回执返回前替换 pending 记录，保留成功发送的原消息映射，随后仍编辑同一消息。
- 不新增依赖、不迁移数据库；自动化验证不等同于真实 Telegram 验收。实现完成后用户已另行授权提交、push、合并和部署，发布版本为 1.1.6。
